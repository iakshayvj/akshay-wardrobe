# Akshay's Uses This

**A living inventory of the clothes, shoes, watches and devices I actually use.**

[Open the catalog](https://iakshayvj.github.io/akshay-wardrobe/)

## The story

This started as a practical problem: I owned enough clothes that buying or styling from memory stopped working. I wanted every real item in one clean, mobile catalog with the correct product image, useful filters and a way to build outfits from what I already own.

It grew into my personal "Uses This" page. The current catalog has 103 items across clothing, shoes, watches and devices, and it is meant to keep growing with me.

## What it does

| | Feature | What it does |
|---|---|---|
| 🧥 | Real inventory | Catalogs 103 items I own and use |
| 🔎 | Filters and sort | Browses by type and brand without digging through order history |
| 🧩 | Outfit tray | Lets me combine pieces and complete an outfit from the existing wardrobe |
| 🎨 | Taste rules | Keeps combinations around earthy neutrals with one statement colour at most |
| ⌚ | More than clothes | Includes watches and devices in the same personal inventory |
| 📱 | Mobile catalog | Designed to be useful while shopping or getting dressed |

## The honest bit

This is a curated personal inventory, not an automatically complete record. Product images and availability can change at their original sources, and new purchases still need to be added. Outfit suggestions are rules-based today rather than learned from wear history.

## Run it locally

Open `index.html` in a browser. The project is a static site with no account or backend.

## Built with Instinct

I supplied the brief, corrected the inventory and set the visual and outfit direction. **Instinct reconstructed the catalog from my purchase history and inputs, matched items to product imagery, designed and rebuilt the interface through several iterations, implemented the filters and outfit builder, checked the final inventory, and published it to GitHub Pages.**
